# DM Sans bundled fonts (offline support)

Place these four font files here so the app works without network:

- `DMSans-Regular.ttf`
- `DMSans-Medium.ttf`
- `DMSans-SemiBold.ttf`
- `DMSans-Bold.ttf`

**How to get them:** Go to https://fonts.google.com/specimen/DM+Sans and click **"Download family"**. From the zip, copy the four static .ttf files above into this `assets/fonts/` folder (the zip may use similar names like `DMSans-Regular.ttf`).

After adding the files, run `flutter pub get` and rebuild.
